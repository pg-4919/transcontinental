## Transcontinental Railroad ##

<img width="1832" height="440" alt="image" src="https://github.com/user-attachments/assets/a833281d-708a-4680-b81a-d59cf5a4e437" />

This little web game was inspired by the Oregon Trail and was made for a history class project about the Transcontinental Railroad. Players progress along the railroad by means of answering historical trivia questions and have to deal with random events that boost or hinder their progress. Players can choose to be either a Chinese immigrant working on the Central Pacific line or an Irish veteran of the Civil War working on the Union Pacific line.

The game is not fully polished as it is an older project, and contains some bugs. We don't intend to continue maintaining the game at this point.
